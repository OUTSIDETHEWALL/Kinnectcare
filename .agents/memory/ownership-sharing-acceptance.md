to select the source of a startup traffic correction. Do not infer that a later
security check dominates a queue simply because it duplicates an endpoint.

**Why:** Physical attribution contradicted the earlier second-verification
explanation. The user requires reducing evidenced redundant traffic while
protecting authorization and the working moving-GPS baseline.

**How to apply:** Keep request-origin diagnostics available through physical
validation. Report synthetic request/queue reductions separately from observed
phone startup improvement; local success does not authorize a binary or release.
